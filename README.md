### 🐧 Linux Lab — Laboratório prático de Linux

Repositório com documentação e exercícios práticos realizados em ambiente Ubuntu virtualizado, explorando conhecimentos úteis para Suporte Técnico e Infraestrutura de TI.

- Navegação e gerenciamento de arquivos e diretórios.
- Gerenciamento de usuários e grupos.
- Permissões de arquivos e diretórios.
- Monitoramento e gerenciamento de processos.
- Armazenamento e informações de disco.
- Comandos e diagnósticos básicos de rede.

**Tecnologias:** Linux, Ubuntu, VirtualBox, terminal, Git e GitHub.

🔗 [Acessar portfólio](https://github.com/mxtheusz7/portfolio-hackers-do-bem)
